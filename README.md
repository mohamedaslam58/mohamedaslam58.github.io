# Azarch Design Studio Website

A luxury, modern website designed for **Azarch Design Studio**—specializing in architectural drafting, 3D visualization, and interior design. Built with clean HTML5, Tailwind CSS, and vanilla JavaScript.

---

## 🌐 Live Demo
[View Live Site](https://your-username.github.io/azarch/)

---

## ✨ Features
* **Responsive Architecture**: Fully optimized for mobile, tablet, and desktop views.
* **Modern Luxury Design**: Dark-mode aesthetic featuring gold accents (`#D4AF37`) and clean typography.
* **Multi-Page Layout**: Dedicated pages for seamless site navigation.
* **Dynamic Active Link Handling**: Automatically highlights active navigation items based on the current page path.
